# Architecture Decision Records

ADRs capture decisions that materially constrain architecture, product identity, security, compatibility, or delivery.

## Status values

- Proposed: under review and not yet binding.
- Accepted: current project rule.
- Superseded: replaced by a newer ADR.
- Rejected: considered but not adopted.

Do not rewrite an accepted decision to change its outcome. Add a new ADR that supersedes it so the reasoning remains auditable.
